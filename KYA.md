Know Your Assumptions (KYA) for Crystal-pool:

Blockchain Validity: We assume that the Ergo blockchain will always provide the ultimate source of truth for transaction validity and account balances.
Unconfirmed Transactions: The system operates on unconfirmed transactions to provide real-time trading. Users should be aware that actions based on unconfirmed transactions may be reversed if these transactions fail to confirm.
State Rollbacks: In cases where unconfirmed transactions don't make it into the blockchain, the system may need to roll back certain operations. This could affect open orders or recent trades.
UI Indicators: Users are expected to understand and monitor the difference between confirmed and unconfirmed balances as displayed in the user interface.
Centralized Matcher: While the funds remain secured by blockchain mechanisms, the order matching is performed by a centralized service. Users should be aware of the implications of this hybrid model.
Real-time vs. Confirmed State: There may be temporary discrepancies between the real-time state shown by the matcher and the confirmed state on the blockchain.
Network Conditions: The performance and reliability of the system may be affected by Ergo network conditions, potentially impacting transaction confirmation times.

By using Crystal-pool, users acknowledge and accept these assumptions and the associated risks.
